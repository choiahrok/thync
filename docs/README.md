# 문서 목차

[프로젝트 소개와 빠른 시작](../README.md)

처음 사용한다면 **설치 → 화면 사용법 → 필요한 연동 설정** 순서로 읽으면 됩니다. 이미 실행 중이라면 아래에서 하려는 일에 맞는 문서를 선택합니다.

## 처음 사용하는 경우

1. [설치와 실행](getting-started.md)에서 준비물, 서버 실행, 토큰으로 첫 접속하는 방법을 확인합니다.
2. [화면, 칸반과 MCP 사용법](usage.md)에서 작업 상태를 읽고 카드를 관리하는 방법을 확인합니다. AI 에이전트 연결도 이 문서에서 안내합니다.
3. [설정과 외부 서비스 연결](configuration.md)에서 수집할 출처를 고르고 Jira·Notion을 연결합니다.

## 작업을 맡기거나 데이터 범위를 확인하는 경우

| 하려는 일 | 문서 |
| --- | --- |
| 다른 사람의 PR을 리뷰하거나 내 PR의 후속 작업을 Claude에게 맡깁니다 | [Claude에게 일 맡기기](handoff.md): 준비 조건, 위임 절차, 자동 승인 조건, tmux 세션 확인 |
| 저장 위치와 외부 전송, 서비스별 쓰기 권한을 확인합니다 | [데이터와 보안](security.md): 접근 토큰, 데이터 흐름, PR 위임의 권한 범위 |
