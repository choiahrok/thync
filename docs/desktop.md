# 데스크톱 구름 (macOS)

[문서 목차](README.md) · [프로젝트 소개](../README.md)

`desktop/`은 thync 를 macOS 화면 위에 띄우는 작은 앱입니다. 선글라스를 쓴 구름이 다른 앱 위에서 화면 곳곳을 돌아다니며 thync 상태를 보여 줍니다. 웹 화면(`http://127.0.0.1:8765/`)은 그대로 쓸 수 있고, 앱은 같은 화면을 창 하나로 열어 줄 뿐입니다. [Tauri](https://tauri.app) 로 만들었고 앱 크기는 7MB 안팎입니다.

## 구름이 보여 주는 것

| 상태 | 구름 |
| --- | --- |
| 세션이 내 답을 기다림 | 멈춰서 선글라스를 올리고 통통 튑니다. 말풍선에 서버·세션·질문이 보이고, macOS 알림과 소리가 한 번 울립니다 |
| 백그라운드 작업이나 2분 넘게 이어진 작업이 끝남 | 초록빛을 띠고 제자리에서 6초 동안 뛰며 ✓ 표시를 띄웁니다. 말풍선에 서버·세션이 보이고, 끝난 세션마다 macOS 알림이 한 번 울립니다. 짧게 주고받는 턴이 끝날 때는 조용합니다 |
| Claude 가 혼자 작업 중 | 보라빛을 띠고 번개가 번쩍이며 빨리 돌아다닙니다. ⚡ 옆 숫자는 작업 중인 세션 수입니다 |
| 내가 집중해서 작업 중 | 하늘색 빛을 띠고 천천히 다닙니다 |
| 리뷰 요청이 있음 | 편지가 구름 주위를 돕니다 |
| 아무 일 없음 | 천천히 떠다닙니다 |
| 허브가 응답하지 않음 | 회색으로 가라앉아 좁니다. 앱이 허브를 한 번 켜 봅니다 |

- **누르기:** thync 창이 열립니다. 질문이 와 있으면 답하는 창이 바로 뜹니다.
- **끌기:** 원하는 곳으로 옮기면 잠시 그 자리에 머뭅니다.
- **마우스 올리기:** 멈춰서 집중·작업·리뷰 수와 서버 연결 상태를 보여 줍니다.
- **메뉴 막대 구름 아이콘:** thync 열기, 구름 숨기기/보이기, 허브 켜기, 종료가 있습니다. 앱은 Dock 에 나오지 않습니다.

## 만들기와 실행

Rust 와 Node.js 가 필요합니다. Rust 는 `brew install rustup && rustup default stable` 로 설치할 수 있습니다.

```bash
cd desktop
npm install
npm run build
open src-tauri/target/release/bundle/macos/Thync.app
```

처음 빌드는 몇 분 걸립니다. 만든 `Thync.app` 을 `/Applications` 로 옮겨 써도 됩니다. 서명하지 않은 앱이라 처음 한 번은 우클릭 → 열기로 허용합니다. 알림은 처음 질문이 올 때 macOS 가 허용 여부를 묻습니다.

## 허브와의 관계

- 구름은 2초마다 허브의 `GET /status.json`(대기 질문, 작업·집중·리뷰 수, 세션별 상태, 서버 연결 상태)을 읽습니다. 토큰은 앱 안에서만 `~/.thync/token` 에서 읽고, 구름 화면에는 넘기지 않습니다.
- 허브가 응답하지 않으면 앱이 한 번 켭니다. `~/.thync/run.sh` 가 있으면 그것을, 없으면 앱을 만든 저장소에서 `python3 -m thync` 를 로그인 셸로 실행합니다. 허브는 앱을 꺼도 계속 돌아갑니다.
- thync 창은 허브의 웹 화면을 그대로 띄우며, 앱의 기능(명령)에는 접근할 수 없습니다.
