# Claude에게 일 맡기기

[문서 목차](README.md) · [프로젝트 소개](../README.md)

PR을 Claude에게 맡기면 다른 사람의 PR은 리뷰하고, 내 PR은 로컬 저장소에서 후속 작업을 수행합니다. 두 방식은 필요한 준비물과 실행 권한이 다릅니다.

## 실행 조건 확인

공통으로 서버 환경에서 `claude` CLI를 사용할 수 있어야 하며, `sources`에 `claude_code`가 포함되어야 합니다. 조건을 충족하면 화면에 '맡긴 일' 칸이 표시됩니다.

| 대상 | 추가로 필요한 준비물 | 수행하는 작업 |
| --- | --- | --- |
| 다른 사람의 PR | GitHub 조회·리뷰 등록 권한이 있는 `gh` 인증, 아래 리뷰 명령의 옵션을 지원하는 `claude` CLI | PR을 읽고 GitHub에 리뷰를 게시합니다 |
| 내 PR | `tmux`, 해당 PR의 로컬 저장소, 설치된 Claude Code 스킬 | 스킬이 코드를 수정하고 push하는 등 후속 작업을 수행합니다 |

내 PR에 사용할 기본 스킬 이름은 `pr-review-watch`입니다. 이 스킬은 thync에 포함되어 있지 않으므로, 자신의 Claude Code에 설치된 스킬 이름으로 `reflex_skills.sent`를 설정합니다([설정 키](configuration.md#설정-키)).

## 화면에서 맡기기

1. 뇌 그래프의 PR 노드를 맨 아래 줄기에 끌어 놓거나, PR 칸반 카드를 '맡긴 일' 칸으로 옮깁니다.
2. 확인 창에서 대상과 작업 내용을 확인합니다. 다른 사람의 PR은 자동 승인 옵션도 선택할 수 있습니다.
3. 실행을 확인한 뒤 '맡긴 일' 카드에서 상태를 확인합니다.

기능이 비활성화되어 있으면 '맡긴 일' 칸이 보이지 않으며, 줄기에 놓아도 작업을 실행하지 않습니다.

<a id="남의-pr-thync가-리뷰를-받아-올린다"></a>

## 다른 사람의 PR 리뷰

### 리뷰 절차

1. **자료를 받습니다.** thync가 `gh`로 PR 정보와 diff를 임시 폴더에 받습니다. diff는 최대 400KB까지 사용합니다.
2. **읽기 도구로 리뷰합니다.** 해당 폴더에서 아래 명령의 옵션으로 Claude를 실행하고, `--json-schema`로 정한 JSON 형식의 요약과 줄 코멘트를 받습니다.
3. **결과를 검증하고 게시합니다.** diff에 없는 줄의 코멘트는 리뷰 본문으로 옮깁니다. 리뷰는 처음 받아 온 커밋에 고정하므로, 실행 도중 새로 push된 커밋은 포함하지 않습니다.

리뷰 실행에는 다음 옵션을 사용합니다.

```text
claude -p --restricted --strict-mcp-config --no-session-persistence --tools Read,Grep,Glob
```

명령 실행·파일 수정·웹 접근 도구를 허용하지 않으며, 파일 도구는 임시 폴더 밖을 읽지 못하도록 제한합니다. 사용자 설정과 MCP 서버를 불러오지 않고 세션 로그도 남기지 않습니다.

### 자동 승인 조건

다음 조건을 모두 충족하면 리뷰를 승인(`APPROVE`)으로 게시합니다.

- 사용자가 확인 창에서 "지적이 없으면 approve"를 선택했습니다.
- Claude의 결과 어디에도 🔴·🟡 지적이 없습니다.
- 크기 제한으로 diff를 자르지 않았습니다.

그 외에는 의견(`COMMENT`)으로 게시합니다. PR 제목·본문·diff에 숨은 지시가 리뷰 문구나 승인 판단을 왜곡할 수 있으므로, 자동 승인은 신뢰하는 사람의 PR에만 선택합니다.

<a id="내-pr-tmux에서-스킬을-띄운다"></a>

## 내 PR의 후속 작업

1. **로컬 저장소를 찾습니다.** `company_roots` 바로 아래 폴더와 알려진 세션 폴더 중 `origin` 주소가 PR 저장소와 일치하는 Git 저장소를 선택합니다. GitHub에서 저장소 이름이 바뀐 경우도 확인합니다.
2. **tmux에서 스킬을 실행합니다.** `reflex_skills.sent`에 설정한 스킬을 해당 저장소에서 실행합니다. 파일 수정과 push가 필요한 작업이므로 `--permission-mode auto`를 사용합니다.
3. **세션에서 진행 상황을 확인합니다.** 실행한 세션은 '맡긴 일' 칸과 뇌 맨 아래에 하늘색으로 표시합니다. 아래 명령으로 세션에 접속할 수 있습니다.

```bash
tmux attach -t thync-<저장소>-<번호>
```

`~/.thync`·`~/.ssh`·`~/.claude/settings.json`은 파일 읽기 도구의 금지 목록에 포함합니다. 이 제한의 범위와 리뷰어 코멘트 등 외부 입력을 다룰 때의 주의점은 [데이터와 보안](security.md#pr-위임의-권한-범위)에 설명합니다.

## 진행 상태 확인

다른 사람의 PR 리뷰는 최대 30분 동안 실행하며, 카드에 다음 상태를 표시합니다. 상태와 결과는 `reflex.json`에 저장합니다.

| 저장 값 | 화면의 의미 |
| --- | --- |
| `running` | 리뷰 중입니다 |
| `posted` | 리뷰를 게시했습니다 |
| `approved` | 승인 리뷰를 게시했습니다 |
| `failed` | 리뷰에 실패했습니다 |

내 PR의 후속 작업은 tmux 세션에 접속해 확인합니다.
