# 화면, 칸반과 MCP 사용법

[문서 목차](README.md) · [프로젝트 소개](../README.md)

이 문서는 화면에서 작업 상태를 확인하고, 칸반 카드를 편집하고, AI 에이전트를 연결하는 순서로 안내합니다.

thync의 **작업 단위**는 같은 Jira 에픽·티켓, 브랜치 또는 저장소로 묶은 관련 활동입니다. **집중**은 최근 활동에서 추정한 상태이고, **백그라운드**는 진행 중이지만 지금 직접 관여하지 않는 작업을 뜻합니다.

## 화면 읽기

- **뇌**: 작업 단위마다 노드가 한자리에 모입니다. 집중도가 높은 작업일수록 앞쪽(이마)에, 덜 집중하는 작업은 옆과 뒤에 놓입니다. 새 활동이 생기면 그 노드에서 빛 입자가 퍼집니다.
- **오른쪽 패널**: 내가 집중하는 일(최대 4개), 백그라운드, 나에게 온 리뷰 요청, 리뷰를 기다리는 내 PR. 항목을 누르면 뇌에서 비추고, ⓘ 를 누르면 상세 내용이 표시됩니다.
- **칸반**: Todo, 진행 중, 백그라운드 진행 중, 맡긴 일, 완료. 카드를 끌어 옮기고, 제목이나 메모를 두 번 눌러 바로 수정합니다. 카드 하나가 Markdown 파일 하나입니다.
- **색**: 금색 = 집중, 하늘색 = 백그라운드·맡긴 일, 주황 = 리뷰 요청, 보라 = 내 PR, 파랑·초록 = 회사·개인.

밝기와 배치 규칙은 주의와 기억에 관한 연구에서 가져왔습니다. 자세한 내용은 [뇌 모델과 근거](brain-model.md)에 있습니다.

## 뇌의 위치별 의미

작업 단위는 집중도에 따라 앞에서 뒤로 배치합니다. 전두엽·두정엽의 과제 네트워크와 뒤쪽 정중앙의 기본 모드 네트워크 연구에서 착안한 시각화입니다.

| 위치 | 놓이는 일 |
| --- | --- |
| 대뇌 앞쪽, 이마 | 가장 최근에 손댄, 지금 가장 집중하는 일 하나 |
| 대뇌 위·앞쪽 양옆 | 그 밖에 집중하는 일. 이마와 합쳐 활동 출처 최대 4개를 표시합니다 |
| 대뇌 옆, 관자놀이·정수리 뒤 | 진행 중이지만 덜 집중하는 일, 나에게 온 리뷰 요청 |
| 대뇌 뒤쪽, 뒤통수 | Claude가 일하지만 한동안 입력하지 않은 세션, 지금 손대지 않는 진행 중 티켓 |
| 소뇌 | 리뷰를 기다리는 내 PR만 남은 일 |
| 척수, 척수 반사 | Claude에게 맡긴 일. PR 노드를 줄기에 끌어 놓아 위임합니다 |

중뇌처럼 뇌 안쪽의 자리는 노드가 겉에서 보이지 않아 사용하지 않습니다. 소뇌와 척수는 기다리는 일과 맡긴 일을 구분하는 디자인상의 비유입니다. 특히 척수는 신경 쓰지 않아도 처리되는 일을 뇌를 거치지 않는 반사에 빗댄 것입니다.

## 칸반 카드 파일

카드를 직접 편집하거나 저장하면 Markdown 파일로 관리합니다. 파일 상단의 속성 영역(frontmatter)에 `id`, `title`, `column`(`todo`, `doing`, `background`, `done`), `profile`을 지정하고, 본문에 메모를 작성합니다. 화면에서 옮기거나 고치면 이 파일이 바뀌고, 아무 편집기에서 고쳐도 다음 화면 갱신 때 반영됩니다(기본 2초 주기). 파일을 새로 만들면 카드가 추가됩니다(`id`가 없으면 손으로 만든 카드로 봅니다). 손대지 않은 자동 카드는 파일을 만들지 않습니다.

```markdown
---
id: jira:ABC-123
title: 결제 API 재시도
column: doing
profile: 회사
---

메모는 여기에 자유롭게 작성합니다.
```

frontmatter는 한 줄짜리 `키: 값`을 읽는 단순 형식입니다. 일반 YAML의 중첩 구조나 여러 줄 값은 지원하지 않습니다. `profile`은 `회사` 또는 `개인`을 사용합니다.

| 화면의 칸 | 파일의 `column` | 용도 |
| --- | --- | --- |
| Todo | `todo` | 시작 전 작업 |
| 진행 중 | `doing` | 지금 진행하는 작업 |
| 백그라운드 진행 중 | `background` | 입력을 기다리지 않고 진행 중인 작업 |
| 완료 | `done` | 끝난 작업 |
| 맡긴 일 | 파일로 지정하지 않음 | PR 위임으로 생성됩니다. [Claude에게 일 맡기기](handoff.md) 참고 |

자동 카드의 제목·칸·메모를 고치면 파일이 생깁니다. 파일에 지정한 칸은 자동 분류보다 우선하며, API의 `reset: true`로 칸 지정만 해제할 수 있습니다. 자동 분류는 활동·리뷰 상태·Jira 상태를 사용합니다([구현](../thync/board.py)).

## 에이전트에서 지금 하는 일 묻기 (MCP)

thync에는 MCP(Model Context Protocol) 서버가 포함되어 있습니다. Claude Code 같은 에이전트가 `thync_now` 도구를 부르면 집중, 백그라운드, 나에게 온 리뷰 요청, 리뷰를 기다리는 내 PR, 맡긴 일을 한 줄씩 짧은 글(보통 2천 자 안팎)로 반환합니다. 여러 기록을 직접 조회하는 대신 요약을 받아, 에이전트에 전달할 맥락을 줄일 수 있습니다. `profile`(`회사`·`개인`)과 `days`로 범위를 좁힐 수 있습니다. 읽기만 하고 아무것도 쓰지 않습니다.

```bash
claude mcp add thync -e PYTHONPATH="/absolute/path/to/thync" -- python3 -m thync.mcp
```

`/absolute/path/to/thync`는 저장소의 절대 경로로 바꿉니다. 도구의 `days`는 1~30이며 기본값은 7입니다. HTTP 서버와 별도의 표준 입출력 프로세스로 실행하므로 브라우저 접근 토큰은 필요하지 않습니다. 같은 사용자와 `THYNC_HOME`을 사용하면 설정과 저장 파일을 공유합니다.
